# Amane Stock Manager 0.2.0

## 新增功能

- 使用管理员账号登录，连接本地库存与云端库存工作台。
- 显示同步进度、同步状态、最近同步时间，支持失败重试和断线恢复。
- 并发修改冲突时保留本地备份，可选择采用云端版本或另存为新库存，不静默覆盖。
- 商品新增“上架”开关；仅上架商品会通过公开接口出现在主页商店。
- 支持商品图片方形裁切和独立 CAD 商店定价，原价、折扣、现价联动。
- 保留离线 JSON 库存、扫码出入库、手动调整数量、多币种统计和 CSV/XLSX/JSON 导出。

## 更新与数据说明

- 已安装版本可通过软件中的“检查更新”下载 v0.2.0，再选择重启安装。
- 仅登录不会上传库存；选择“连接并上传当前库存”才授权该文件自动同步。
- 旧库存首次保存前会备份原始文件，再迁移至 v7。请保留备份；不要使用旧版软件继续编辑已经迁移的文件。
- 本次提供完整更新包，沿用原 GitHub Velopack win 稳定通道及兼容索引。旧版发布保留。
- 安装包未进行代码签名，Windows 可能显示未知发布者提示。
