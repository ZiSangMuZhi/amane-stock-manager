# Amane Stock Manager 0.2.1

- 修复已连接库存被云端删除后，同步一直返回 HTTP 410 的问题；确认云端已删除或不存在后，自动备份本地文件并重新上传为新的云端库存。
- 同时处理完全删除后的 HTTP 404，以及旧库存首次重新连接时遇到的删除记录冲突。
- 保留本地库存名称、商品、数量、价格、上架选择和出入库流水；重新建立同步关联后，后续修改继续正常同步。
- 保存重新上传的目标编号与请求内容，断网或应用重启后继续同一次上传，避免重复创建库存。登录失效、权限不足、网络错误和普通网页 404 不会触发重新创建。
- 改进安装包制作流程，排除开发、测试及本地辅助文件，构建失败时立即停止。

已安装版本可在应用中选择“检查更新”，下载完成后重启安装。此次沿用原 GitHub Velopack 更新通道，库存文件格式不变。

重新上传会建立新的云端库存和商品记录，保留原云端的删除记录及历史引用。仅存于云端商店的独立注册、图片或价格编辑不会迁移到新记录，需在商店管理中重新配置；本地商品已有的资料按本地状态上传。

验证使用临时合成库存与模拟传输，不向真实账号上传测试数据。版本验收记录另存于本地发布报告。
