# Amane Stock Manager 0.2.2

- 修复商品在次元商店注册后，应用修改价格不能同步到商店的问题。卡片的 CAD 售价和“商店 CAD 定价”均支持同步；商店定价也会更新卡片的 CAD 售价。
- 进价保持独立。非 CAD 售价、切换币种和清空售价不会自动换汇或将商店商品改为免费。直接调高 CAD 售价时，必要时同步提高原价；调低时保留原价并重算折扣。
- 价格保存使用持久化待发记录。库存和商店价格分别确认，断网、响应丢失和重启后继续重试；遇到商店并发修改时，保留输入并提供明确的价格冲突处理按钮。
- 保护编辑中的价格草稿，库存刷新不会清除尚未保存的输入。已注册商品的图片与上架状态提示由商店后台管理，普通库存同步保留商店名称、图片、分类及上架状态。
- 云同步服务切换至迁移后的 `https://api.amaneacg.space`。升级后需要重新登录一次，原有库存文件和同步记录保留。

已安装版本可使用“检查更新”下载并重启安装。此次继续使用 Windows x64、`win` 通道，库存 JSON 仍为 schema 7。同步已注册商品价格需要管理员账号具备库存、商品和定价管理权限。

测试使用临时合成数据与模拟服务，不修改真实商品、订单或库存。没有进行真实账户的线上改价，也不会改动历史订单的价格快照。
