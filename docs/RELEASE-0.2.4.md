# Amane Stock Manager 0.2.4

- 库存版本冲突时新增“使用本地覆盖云端”。二次确认后先在当前文件旁保存云端原始副本，再覆盖同一库存 ID；云端再次变化会重新提示冲突，不自动强行重试。
- 新增商品选择与批量上架、下架，单次最多 200 件，仅处理当前筛选结果中选中的商品。上架时自动注册尚未注册的关联商品，保留已有分类和定价。
- 已注册商品也能在应用中选择、裁切、保存或移除主图。上传和保存分开，图片保存不提交尚未保存的价格草稿；商品卡片优先显示商店主图。
- 新的商店操作先保存恢复记录，断网或响应丢失后重试同一请求。保存失败保留选择和图片草稿，后台改变主图时提示重新核对。

批量上下架和新的主图保存需要 Mac 服务端配套升级。应用会检查服务端能力，尚未升级时显示等待提示；部署后点击“立即同步 / 重试”即可启用，无需再次更新应用。常规库存同步、价格同步和“使用本地覆盖云端”可继续使用。

通过应用内“检查更新”安装。本次保留现有登录、本地库存和待同步记录。覆盖前的云端备份以 `.cloud-v版本.backup-时间-标识.json` 保存在当前库存文件旁，可作为独立库存文件打开。
